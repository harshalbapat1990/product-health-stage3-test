# Security Policy

## Scope

This is a disposable repository used to test repository health,
security integrations, and CI/CD monitoring.

It does not contain production code or production credentials.

## Reporting

Do not submit real credentials, confidential information, or
sensitive production data to this repository.

If a real credential is accidentally committed, revoke it immediately
and follow the credential owner's incident-response process.

## Security Testing

Security features may be enabled to test the ingestion of:

- Dependabot alerts
- Code-scanning alerts
- Secret-scanning alerts, where available

Only safe, non-sensitive test data should be used.
